# Welcome

The site is under construction. Posts will appear under `content/posts/`.

## Publish flow

1. Add a Markdown file under `content/posts/` with frontmatter:
   ```
   ---
   title: My Post
   date: 2026-07-09
   tags: [intro]
   author: rock
   ---
   ```
2. Open a PR.
3. Merge into `main`.
4. GitHub Actions deploys to Pages.
